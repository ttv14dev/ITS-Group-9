# TIẾN ĐỘ CÔNG VIỆC - THÀNH VIÊN 3

## 1. Thông tin dự án

- Dự án: ITS Group 9 - Nhận diện phương tiện ưu tiên
- Thành viên: Nguyễn Trí Quý
- Vị trí: Frontend - Giao diện chính và chức năng chọn loại xe
- Branch: tri-quy/tv3

## 2. Công việc được phân công

- Xây dựng bố cục trang chính (index.html).
- Thiết kế giao diện dùng chung cho toàn trang (css/style.css).
- Xây dựng form chọn loại phương tiện.
- Kết nối API Backend (POST /api/detect/type) để gửi loại xe đã chọn (js/api.js).
- Hiển thị kết quả nhận diện và độ tin cậy.
- Đảm bảo giao diện hiển thị tốt trên điện thoại (responsive).
- Phối hợp với Thành viên 4 để dùng chung khối hiển thị kết quả và file api.js.

## 3. Công nghệ sử dụng

- HTML: Xây dựng bố cục trang.
- CSS: Thiết kế giao diện, responsive.
- JavaScript: Xử lý form và gọi API.
- FastAPI: Kết nối Backend.

## 4. Kế hoạch thực hiện

- Giai đoạn 1: Khảo sát cấu trúc dự án.
- Giai đoạn 2: Xây dựng bố cục trang index.html và giao diện CSS.
- Giai đoạn 3: Xây dựng form chọn loại xe và khối hiển thị kết quả.
- Giai đoạn 4: Viết api.js, kết nối API nhận diện theo loại xe.
- Giai đoạn 5: Kiểm thử, hoàn thiện giao diện và gộp code bằng Pull Request.

## 5. Tiến độ hiện tại

- Đã tải mã nguồn dự án từ GitHub.
- Đã thiết lập môi trường làm việc trên VS Code.
- Đã khảo sát cấu trúc thư mục Frontend và Backend.
- Đã xác định phạm vi công việc và kế hoạch triển khai.
- Giao diện index đang trong giai đoạn chuẩn bị thực hiện.
